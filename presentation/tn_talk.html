Compositional data

A simplex is the convex set of all vectors with non-negative parts that sum to a constant:

\[ \mathcal S^{c}_{k}=\Bigl\{(z_1,\dots,z_k)^{\top}\in\R^{k}\ \Bigm|\ z_i\ge 0,\ \ \sum_{i=1}^{k}z_i=c\Bigr\} \]

It is common to set \(c=1\). We refer to data from this space as compositional data.

Compositional data

Compositional data: a practical view

Let \(\mathbf Y=(Y_1,Y_2,\dots,Y_K)\) be a vector with positive parts. The compositional transformation (closure)

\[ \mathbf S=\Bigl(\frac{Y_1}{\sum_{i=1}^{K}Y_i},\ \dots,\ \frac{Y_K}{\sum_{i=1}^{K}Y_i}\Bigr) \]

gives a vector that lies in the simplex.

Lost: the absolute scale. \(\mathbf Y\) cannot be recovered from \(\mathbf S\): \(\mathbf Y\) and \(10\,\mathbf Y\) give the same \(\mathbf S\).

Kept: the relative information. For any two parts \(i\) and \(j\),

\[ \frac{Y_i}{Y_j}=\frac{S_i}{S_j}. \]

TARGET: 28 seconds

SAY:

Suppose we observe several positive quantities. We divide each quantity by their total. This operation is called closure.

The resulting proportions sum to one. We lose the original scale: two vectors with the same proportions but different totals give the same composition.

Random forests for compositional responses

Random forest: overview

A random forest is an ensemble of decision trees, usually trained on bootstrap samples of the data. Key tuning parameters:

  • Number of trees (\(B\)): more trees improve stability but increase the cost
  • Tree depth (\(d_{\max}\)): controls model complexity and overfitting
  • Minimum node size (\(n_{\min}\)): the minimum number of observations required to split a node
  • Covariates per split (\(m_{\text{try}}\)): the number of randomly selected covariates considered at each split; chosen for the task and tuned with validation

TARGET: 25 seconds

SAY:

A random forest combines many decision trees. Each tree divides the predictor space into smaller regions. Predictions combine information across trees.

Important settings include the number of trees, the variables considered at each split, and the stopping rules.

Node model 1 · on the simplex

The Dirichlet distribution eq. (8)

\[ f(\bz;\boldsymbol\alpha)=\frac{\Gamma(\alpha_0)}{\prod_{j=1}^{k}\Gamma(\alpha_j)}\prod_{j=1}^{k}z_j^{\alpha_j-1},\qquad \alpha_0=\sum_{j=1}^{k}\alpha_j \]

\(k\) positive parameters; \(m_i=\alpha_i/\alpha_0\). With \(\boldsymbol\alpha=\alpha_0\mathbf m\): \(E(\mathbf Z)=\mathbf m\), \(\operatorname{Cov}(\mathbf Z)=\dfrac{\diag(\mathbf m)-\mathbf m\mathbf m^{\top}}{\alpha_0+1}\)  (9).

A limited covariance matrix

  • \(k\) parameters for \(k-1\) free means and \(k(k-1)/2\) covariances: once the mean is fixed, one scalar \(\alpha_0\) sets the whole matrix
  • every off-diagonal covariance is negative, \(-m_im_j/(\alpha_0+1)\); the correlations depend on \(\mathbf m\) only: \(\rho_{ij}=-\sqrt{\tfrac{m_im_j}{(1-m_i)(1-m_j)}}\)
  • no independent parameter for orientation or elongation at a fixed mean

Support: the open simplex, \(z_j>0\) (2): a composition with a zero part is outside it.

150 draws from Dir(α) · contours at 10, 30, 50, 70, 90% of the peak

Node model 3 · the tangent-normal (TN) distribution

The tangent-normal construction Def. 1, eqs. (14)–(16)

Mean direction \(\bmu\); tangent plane \(T_{\bmu}=\{\mathbf x:\bmu^{\top}\mathbf x=0\}\) with orthonormal basis \(\bK\) (\(\bK^{\top}\bK=\mathbf I\)). Construction:

  1. Down to the tangent plane: \(\bv=\bK^{\top}\bu\), the tangent coordinates (move each point parallel to \(\bmu\)).
  2. A normal distribution on the plane: \(\bV_0\sim N_{k-1}(\mathbf 0,\Lambda)\), \(\Lambda=\diag(\lambda_2,\dots,\lambda_k)\), kept inside the unit ball: \(\bV=\bV_0\mid\|\bV_0\|<1\).
  3. Back to the hemisphere: \(\bU=\psi(\bV)\sim\mathrm{TN}(\bmu,\bK,\Lambda)\), with
\[ \psi(\bv)=\bigl(1-\|\bv\|^2\bigr)^{1/2}\bmu+\bK\bv \tag{14}\]
\[ g(\bu)=\frac{\varphi_{\Lambda}(\bK^{\top}\bu)\;\bmu^{\top}\bu}{\pi_{\Lambda}},\quad \bu\in H_{\bmu} \tag{15}\]

\(\bmu^{\top}\bu\) is the Jacobian of step 3: \(d\bv=(\bmu^{\top}\bu)\,\sigma(d\bu)\) (16). Support: \(H_{\bmu}=\{\bu:\bmu^{\top}\bu>0\}\), not just \(\mathcal O\). Back to the triangle: \(\bz=\bu^2\).

Tangent-normal · estimation and simulation · Section 3.2.3

An efficient approximate TN splitting score

1. Location by moments

\[\hat\bmu=\bs_1/\|\bs_1\|,\qquad \hat\bM=S_2/n_A.\]

2. Profile out the Gaussian shape

\[\hat\ell_G=-\frac{n_A}{2}\log|S_T|+C_{n_A},\qquad S_T=\bB^\top\hat\bM\bB.\]

The term C is linear in node size and cancels from the split gain. B is an orthonormal tangent basis.

Implemented score: \(\hat\ell_G+\widetilde J\). One Cholesky factor computes the log-determinant; the shape parameters need not be fitted explicitly at each threshold.

With \(R=\|\bs_1\|\), \(\bar c=R/n_A\), the implementation uses the delta2 approximation:

\[\widetilde J=n_A\log\bar c-\frac{\hat\bmu^\top S_2\hat\bmu-n_A\bar c^2}{2\bar c^2}.\]

No iterative parameter estimation in this split score. The moment direction is not its full MLE. Exact location MLE generally needs numerical optimisation.

The term \(-n_A\log\pi_\Lambda\) is omitted; the concentration bound controls this approximation. Full truncated TN shape MLE is not the Gaussian covariance estimate.

These steps avoid repeated optimization over all parameters. They define an efficient approximate score, not the exact fully maximized TN likelihood.

Zero components

Zeros remain valid square-root coordinates

Dirichlet: support is the open simplex (2); a zero part lies outside it, so zeros must be replaced first.

Log-ratios: undefined at zero, and highly variable near zero.

Square root: \(\sqrt0=0\) is an ordinary point on the edge of \(\mathcal O\). If \(\bmu\) has positive parts, \(\bmu^{\top}\bu>0\) on \(\mathcal O\), so zero-containing compositions remain in the TN hemisphere; the square root stays bounded.
