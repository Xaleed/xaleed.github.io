
\begin{frame}{How to Plot Compositional Data}
not confirmed:
\note{\small
Here, I want to explain how we plot compositional data.

Consider a few observations, for example five points.

Each observation has three components: $X_1$, $X_2$, and $X_3$.
So we can represent the data in three dimensions.

Now, because the data satisfy $X_1 + X_2 + X_3 = 1$,
all points lie on a plane.

This means the data do not fill the full 3D space.

Because of this constraint, one dimension is redundant.

So instead of using a 3D plot, we use a 2D representation.

This is called the Finetti diagram.

Each point inside the triangle represents a valid composition.
}

\only<1>{
\vspace{2.5cm}
\begin{itemize}
    \item $X_1 + X_2 + X_3 = 1$
    \item Data lie on a plane in 3D
    \item $\Rightarrow$ 2D representation
    \item Finetti diagram
\end{itemize}
