# Compositional random forest conference presentation

Open [tn_talk.html](tn_talk.html) in a modern browser. No build step is required. Keep the assets folder beside the HTML. Plotly and research figures are local; MathJax 3.2.2 and web fonts require internet. Serif/monospace fallback fonts are provided.

The deck has **42 slides**, a **24:18** slide plan and **2,459 spoken words**. Allow about 25 minutes including visual actions and pauses.

## Controls

- Arrow keys, Space, Enter and Page Up/Down: navigate. Home/End: first/last slide.
- F: fullscreen; focus the main presentation window first.
- S: private speaker window with synchronized notes, elapsed time, current target and next-slide title. Allow the popup.
- N: show notes on the presentation itself; this is visible to the audience.
- P: prepare all charts as static images, then open print/PDF. Reload afterwards to return to interactive mode. The ?print query also prepares print mode. Use P rather than the browser's direct print shortcut.
- #7 opens slide 7.
- Slide 2: click the simplex to move the example composition. Slide 8: trace a prediction path.
- Slide 18: independently toggle triangle, sphere, lines and projected observations.
- Slide 23: step through the TN construction. Slide 32: switch Aitchison/RMSE.
